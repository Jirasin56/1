# e-Portfolio ของ จิรสิน กงไกรลาศ

เว็บไซต์ e-Portfolio ที่สร้างด้วย HTML, CSS และ JavaScript เผยแพร่ผ่าน GitHub Pages

🔗 **เว็บไซต์:** https://jirasin56.github.io/eportfolio/
🔗 **Repository:** https://github.com/Jirasin56/eportfolio

## เกี่ยวกับโปรเจกต์

e-Portfolio นี้ใช้แนะนำตัวและรวบรวมผลงานของนักเรียนชั้นมัธยมศึกษาปีที่ 6 โรงเรียนธัญรัตน์ ประกอบด้วยหน้าแรก เกี่ยวกับฉัน ผลงาน และช่องทางติดต่อ ออกแบบให้แสดงผลได้ทั้งบนคอมพิวเตอร์และมือถือ รองรับโหมดมืดตามการตั้งค่าของอุปกรณ์

## โครงสร้างไฟล์

| ไฟล์ | คำอธิบาย |
|------|-----------|
| `index.html` | หน้าเว็บทั้งหมด (โครงสร้าง ตกแต่ง และเครื่องคิดเลข) อยู่ในไฟล์เดียว |
| `profile.jpg` | รูปโปรไฟล์ |
| `README.md` | คำอธิบายโปรเจกต์ |

ข้อมูลส่วนตัวทั้งหมดอยู่ในตัวแปร `PROFILE` ใกล้ท้ายไฟล์ `index.html` แก้ข้อความตรงนั้นแล้วหน้าเว็บจะอัปเดตตาม

## คำอธิบายผลงาน

### เครื่องคิดเลขออนไลน์ (อยู่ในส่วน "ผลงาน" ของ `index.html`)
- **เทคโนโลยี:** HTML, CSS, JavaScript
- **การทำงาน:** กดปุ่มหรือพิมพ์จากคีย์บอร์ดเพื่อคำนวณ บวก ลบ คูณ หาร วงเล็บ และเปอร์เซ็นต์ มีปุ่มล้างค่าและลบทีละตัว ตัวคำนวณเขียนเองด้วย JavaScript ไม่ใช้ `eval`
- **สิ่งที่ได้เรียนรู้:** [เขียนสิ่งที่คุณได้เรียนรู้ เช่น การใช้ฟังก์ชัน JavaScript และการจัดการเหตุการณ์ปุ่มกด]

## วิธีรันบนเครื่อง

เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไรเพิ่ม
